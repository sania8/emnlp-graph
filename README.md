## What it does

The site turns the EMNLP 2026 programme into a three-level graph you can explore by clicking:

| Level | What you see |
|---|---|
| **1. Areas** | Keynotes, Panel, Tutorials, Workshops, Industry Track and Sessions, arranged on a rotating ring. |
| **2. Talks** | The talks in the chosen area, fanned out as a graph. Full titles, never truncated. |
| **3. People** | The speakers, organisers and panelists of the chosen talk, linked to their institutions. The earlier levels stay on screen. |

Click a person to open a popup with their affiliation, research areas, co-authors, a short bio and links to their official website, profile and LinkedIn (when the official pages provide them).

## Highlights

- **Animated, layered navigation.** Each level eases in while the previous one stays visible, so you never lose your place.
- **Readable at a distance.** Large type and large nodes, designed for conference screens as well as laptops.
- **Honest data.** Only what the official pages state is stored. Missing photos, affiliations and links stay blank instead of being guessed.
- **Knowledge-graph backed.** The data is built as an RDF graph (rdflib) and exported to JSON for the site and Turtle for reuse.
- **Static and fast.** The whole site is exported as plain files, with no server to run.
- **Accessible.** Keyboard navigation, visible focus rings, `aria` labels and reduced-motion support.

## Tech stack

- **App:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
- **Graph UI:** custom SVG layout and animation, plus Cytoscape (with fCoSE) for the exploratory graph
- **Data pipeline:** Python, rdflib, standard-library HTML parsing
- **Hosting:** Cloudflare (static assets)

## Getting started

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

Build the static site:

```bash
npm run build      # writes the site to ./out
npx serve out      # preview the exported files
```

## Data pipeline

The graph is generated by `pipeline/build_kg.py` from these official pages at <https://2026.emnlp.org/>:

| Page | Used for |
|---|---|
| `program/` | the session grid |
| `program/keynotes/` | keynote speakers (photo, bio, abstract) |
| `program/industry/` | industry keynotes and the industry panel |
| `program/panel/` | panelists (photo, bio) |
| `program/tutorials/` | tutorial organisers |
| `program/workshops/` | workshops, rooms and announced invited speakers |
| `organization/` | committees (photo, homepage, affiliation) |

Refresh the data:

```bash
pip install -r pipeline/requirements.txt
npm run kg
```

Then commit the updated files in `public/data/` and push.

Test offline with the saved pages:

```bash
python pipeline/build_kg.py --fixtures pipeline/fixtures --out ./tmp-kg
```

### Fixing missing details

People without an affiliation or website on the official pages can be completed in `pipeline/overrides.json`:

```json
{
  "Verena Rieser": { "url": "https://sites.google.com/site/verenateresarieser/" },
  "Example Person": { "affiliation": "Example University", "linkedin": "https://www.linkedin.com/in/example/" }
}
```

Run `npm run kg` again to apply them.

### Known limits

- Workshop pages only name people when an invited speaker is announced, so most workshops have no people attached. Each workshop links to its own website instead.
- Social events and receptions are intentionally left out.
- There is no Birds of a Feather page in the pipeline yet.

## Deploy to Cloudflare

The site is a static export, so Cloudflare only has to serve files.

1. Push this repo to GitHub.
2. In the Cloudflare dashboard, go to **Workers & Pages → Create → Import a repository** and choose this repo.
3. Use these settings:
   - **Build command:** `npm run build`
   - **Deploy command:** `npx wrangler deploy`
4. Every `git push` to `main` redeploys the site.

`wrangler.jsonc` points Cloudflare at the `out` folder:

```jsonc
{
  "name": "emnlp-graph",
  "compatibility_date": "2026-10-24",
  "assets": { "directory": "./out" }
}
```
